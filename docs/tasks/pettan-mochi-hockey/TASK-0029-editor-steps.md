# TASK-0029 エディタでの作業：サウンド（効果音・BGM）

音はすべて **コードで合成** する（2026-11-19 に決定）。音のファイルは使わないので、ダウンロード・ライセンスの確認・インポート設定（Vorbis 圧縮・Streaming）は要らない。ビルドもほぼ増えない。
本物の音に差し替えたくなったら、同じきっかけ（下の表）に AudioClip を割り当てる形に変えられる。

## 鳴る音

| きっかけ | 音 |
|---|---|
| 杵を振る | ひゅっ |
| 杵が当たる | ペッタン！（パンッ＋ドン） |
| 吹っ飛び中に壁で跳ね返る | ぼよん |
| 壁に貼り付く | べちゃっ |
| 壁から復帰する | **ポンッ！**（REQ-034） |
| ダッシュ | しゃっ |
| 餅を打つ | ぱこん（チャージするほど低く大きく） |
| ご飯粒を吸収 | ぴっ |
| 餅のレベルが上がる | 上がっていく 3 つの音 |
| 餅が壁で跳ねる | ぽふ |
| ゴール | 鐘の音が駆け上がる |
| キックオフ・サドンデス | 短い笛 |
| 試合終了 | 長い笛 |
| BGM | 和風の音階の旋律（琴のような音）＋ 三味線のような低音 ＋ 太鼓。8 小節のループ |

- **最初の入力（キー・クリック・ボタン）の前は、BGM も効果音も鳴らない**（REQ-052、ブラウザの決まり）。
- 音量・BGM のテンポ・同時に鳴らせる数などは `GameBalanceConfig` の **Audio**。

---

## 1. Menu シーンに置く

1. `Menu` シーンを開く
2. Hierarchy の何もないところで右クリック → **Create Empty**、名前を `AudioManager`
3. **Add Component → Audio Manager**
4. **Config** に `Assets/_Project/ScriptableObjects/GameBalanceConfig` をドラッグする（Play Bgm はチェックのまま）
5. **Ctrl + S** で保存する

## 2. Match シーンに置く

1. `Match` シーンを開き、手順 1 の 2〜5 と同じことをする

> シーンを移ると BGM は頭から鳴り直す（音は一度作ったら使い回すので、作り直しの待ちはない）。

## 3. 動作確認

### Menu シーンで Play

- [ ] 何も押さないうちは音が鳴らない
- [ ] Enter（またはクリック・ボタン）を押すと BGM が鳴り始める

### Match シーンで Play（何かキーを押してから）

- [ ] BGM が途切れずにループする（つなぎ目でプチッといわない）
- [ ] キックオフで笛が鳴る
- [ ] 杵を振る・当てる・壁で跳ね返る・貼り付く・復帰（ポンッ！）でそれぞれ音が鳴る
- [ ] ダッシュ・シュート・ご飯粒・レベルアップ・餅が壁で跳ねるときに音が鳴る
- [ ] ゴールで鐘の音、試合終了で長い笛が鳴る
- [ ] 音が大きすぎる・小さすぎるものがない（あれば教えてください。Audio の音量か、音ごとの大きさを調整します）

終わったら Unity を閉じて、Claude に知らせる。
公開版（ブラウザ）では、最初のクリックのあとに BGM が鳴り始めるかを確かめる。
