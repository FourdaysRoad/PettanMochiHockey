## タスク概要

累計もち米数から餅のレベル・得点・サイズ倍率・速度倍率・成長ゲージを求める `MochiGrowth` を TDD で作る。

## 完了条件

- [ ] 境界値（0, 2, 3, 5, 6）で正しいレベルを返す
- [ ] 得点・サイズ・速度倍率が設定どおり
- [ ] 成長ゲージが 0〜1 で、Lv.3 は 1
- [ ] 負のもち米数は ArgumentOutOfRangeException
