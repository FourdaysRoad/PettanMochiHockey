## 基本的なテスト要件

### 非保持時の吸収 🔵

**信頼性**: 🔵 *REQ-012*

- 保持者なしで TryAbsorbRice → false、RiceCount は変わらない

### 再吸着禁止 🔵

**信頼性**: 🔵 *REQ-024*

- Release 直後に本人 TryAttach → false、0.3 秒 Tick 後 → true、他人は直後でも true

### Drop は禁止なし 🟡

**信頼性**: 🟡 *dataflow.md*

- 被弾 Drop 直後でも本人以外・本人ともに吸着できる
