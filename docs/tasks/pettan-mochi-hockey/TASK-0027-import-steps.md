# TASK-0027 取り込み手順：Kenney「Cube Pets」

ライセンスの判断は [asset-decisions.md](../../design/pettan-mochi-hockey/asset-decisions.md) を参照（CC0 なので公開リポジトリに入れてよい）。

## 1. ダウンロード（ご自身で）

1. https://kenney.nl/assets/cube-pets を開き、**Download** を押す（寄付の画面が出たら「Continue without donating」などで先へ進める）
2. ダウンロードした zip を、デスクトップなどプロジェクトの外で展開する
3. 展開したフォルダの中身を確認する
   - ウサギ（bunny / rabbit）のモデルがあるか
   - 形式（`.fbx` / `.glb` / `.obj`）と、アニメーションの入り方（モデルに入っているか、別ファイルか）
   - ライセンスのファイル（`License.txt` など）

## 2. プロジェクトに入れる（ご自身で）

1. `Assets/_Project/Art/ThirdParty/KenneyCubePets/` を作る（エクスプローラーで作ってよい）
2. そこに次を入れる
   - **FBX 形式**のモデル（`.fbx`）と、それが使うテクスチャ（`.png`）
     - 全部でなくてよい。ウサギと、ウサギがいなければ代わりに使いたい動物だけで十分
   - ライセンスのファイル（`License.txt`）
3. Unity を開いて読み込ませ、エラーが出ないことを確かめてから **閉じる**

> zip の中にある他の形式（`.glb`、`.obj`、プレビュー画像など）は入れなくてよい（ビルドとリポジトリが大きくなるだけ）。

## 3. Claude に知らせる

入れたファイル名（とウサギがいたかどうか）を教えてください。中身（アニメーションの名前、大きさ、向き）を調べて、プレイヤーのプレハブに組み込む手順と、アニメーションをつなぐコードを用意します。
