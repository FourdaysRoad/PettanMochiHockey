# TASK-0024 エディタ作業手順：ワールド空間のゲージ

CLAUDE.md の決まりで、シーンの YAML は直接書かず、この手順で Unity エディタから作る。
前提：TASK-0021 の手順で `Match` シーンにスポナー・餅があること。

ゲージ（uGUI の World Space Canvas）は実行時にコードで組み立てるので、プレハブは作らない。シーンに部品を 1 つ置くだけ。

## 1. ゲージの部品を置く

1. `Assets/_Project/Scenes/Match` を開く
2. Hierarchy で右クリック → **Create Empty**、名前を `WorldGauges`
3. **Add Component → World Gauge Presenter**
   - Ball：Hierarchy の `MochiBall` をドラッグ（空でもシーンから探すが、入れておく方が確実）
4. **File → Save**（シーン）

## 2. 動作確認（Match シーンを開いて Play）

- [ ] 餅の上に「Lv.1」「x1」と緑の成長ゲージが出て、カメラの方を向いている
- [ ] ご飯粒を吸収するとゲージが伸び、3 個で「Lv.2」「x2」、6 個で「Lv.3」「x3」になる
- [ ] ゴールで餅が消えている間は、頭上のゲージも消える
- [ ] 各プレイヤーの足元に、番号の色のリング（1P 赤・2P 青・3P 緑・4P 黄）と「1P」などの番号が出る
- [ ] 足元のリングの下に水色のスタミナゲージがあり、ダッシュで減って時間で戻る
- [ ] シュートボタンを長押ししている間だけ、リングの上にオレンジのチャージゲージが出る
- [ ] プレイヤーが吹っ飛んだり壁に貼り付いたりしても、足元のゲージの形は崩れない
- [ ] 4 人のとき（Menu から 4 人で始める）、ゲージが重ならずに読める

> 足元のリングの色は「プレイヤー番号」の色で、HUD の「チーム」の色（A 青・B オレンジ）とは別。気になる場合は教えてください。

終わったら Unity を閉じる（バッチモードのテストを動かすため）。
