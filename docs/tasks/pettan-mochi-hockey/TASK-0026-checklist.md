## 操作のおさらい

| | キーボード 1P | キーボード 2P | ゲームパッド |
|---|---|---|---|
| 参加 / 抜ける | J / K | テンキー 1 / 2 | A / B |
| チーム切り替え（対戦設定） | A / D | ← / → | 十字キー・スティックの左右 |
| 開始 | Enter | Enter | Start |
| 移動 | WASD | 矢印 | 左スティック |
| シュート（長押しでチャージ） | J | テンキー 1 | A |
| 杵 | K | テンキー 2 | B |
| ダッシュ | L | テンキー 3 | RB |
| ポーズ | Esc | Esc | Start |
| フルスクリーン | F | F | （ページ右下のボタン） |

> ブラウザでは、ゲームパッドはボタンを一度押すまで認識されない。

## 1. 2vs2（ゲームパッド 4 つ、またはキーボード 2 人 + パッド 2 つ）

- [ ] タイトルで何か押すと対戦設定へ進む（そのボタンで参加はしない）
- [ ] 4 人がそれぞれのボタンで参加し、枠に 1P〜4P・デバイス・チームが出る
- [ ] チームを 2 人ずつに分けると「ENTER or START」の案内になり、開始できる
- [ ] 各チームの 2 人が自陣（A は左、B は右）の別々の場所に並ぶ
- [ ] 3 秒の READY のあと、4 人とも自分のデバイスで動ける（ほかの人の入力で動かない）
- [ ] 足元のリングの番号・色が、対戦設定の 1P〜4P と同じ
- [ ] 味方を杵で叩いても吹っ飛ばない、相手は吹っ飛ぶ
- [ ] 4 人とも、カメラの画面に収まり続ける
- [ ] 時間切れで勝者と最終スコアが出て、「もう一度」で同じ 4 人のまま再戦できる

## 2. 1vs1（キーボード 2 人、またはキーボード + パッド）

- [ ] キーボード 1 人 + ゲームパッド 1 人の混在で遊べる
- [ ] 「タイトルへ」で戻り、参加し直せる

## 3. 試合のルール

- [ ] オウンゴール：自分のゴールに入れると相手の得点になる
- [ ] Lv.2 / Lv.3 の餅で、2 点 / 3 点が入る
- [ ] サドンデス：同点で時間切れになると「SUDDEN DEATH」になり、次のゴールで試合が終わる
- [ ] ゴールのあと餅が 1 秒で中央に戻り、プレイヤーの位置はそのまま

## 4. ゲームパッドの抜き差し（2vs2 か、パッドを使う 1vs1 で）

- [ ] 試合中にゲームパッドを抜くと、自動でポーズし「CONTROLLER DISCONNECTED」が出る
- [ ] 挿し直す（またはほかのパッドをつないでボタンを押す）と、そのプレイヤーがまた操作できる
- [ ] Esc / Start で再開できる

## 5. 公開版で

- [ ] Edge でも、少なくとも 1 試合を通して遊べた
- [ ] テンキー（NumLock をオン）を含め、すべてのキーが効く
