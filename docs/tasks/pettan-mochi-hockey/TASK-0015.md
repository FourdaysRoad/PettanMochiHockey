## タスク概要

球の餅 `MochiBall` と小粒のもち米 `MochiRiceSpawner` を作り、吸着ドリブル・パス／チャージシュート・もち米吸収・レベルに応じたサイズ変更をプロトタイプで動かす。

## 完了条件

- [ ] 正面で近づくと杵の先に吸着してドリブルされる
- [ ] Shoot でチャージ段階に応じた速度で打ち出され、0.3 秒は本人が再吸着できない
- [ ] 保持中にもち米に触れると吸収され、レベルに応じてスケールとコライダーが変わる
- [ ] もち米がプールから 5〜10 個補充される
- [ ] PlayMode テストが通る
