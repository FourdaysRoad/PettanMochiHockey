Launched 中の直進とバウンド、壁到達時の位置・法線、Stuck 中の SlideDown、壁に届かない場合の延長と上限を TDD で作る。

## 完了条件

- [ ] Launched 中は攻撃者の正面方向へ一定速度で直進し、高さは 1 回バウンドする
- [ ] 壁に届いた時点の位置と法線で Stuck になる
