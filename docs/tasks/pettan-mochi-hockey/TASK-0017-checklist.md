## 1. エディタで確認（Match シーンを開いて Play）

### 移動
- [ ] 2 人とも動ける。入力をやめると少し滑ってから止まる
- [ ] ダッシュで一瞬速くなり、連打するとスタミナ切れで出なくなる
- [ ] 壁に引っかからない

### 餅とご飯粒
- [ ] ご飯粒が 5 個出て、1.5 秒ごとに 10 個まで増える
- [ ] 餅に正面から近づくと体の前にくっつく（後ろからは付かない）
- [ ] 持ったままご飯粒に触れると吸収される
- [ ] 成長 3 段階：3 個で 1.5 倍、6 個で 2.5 倍になり、持ち手が遅くなる
- [ ] シュート：すぐ離すと弱く、長押し（最大 1 秒）するほど速い
- [ ] 打った本人はすぐには拾えず、相手はすぐ拾える

### 杵と吹っ飛び
- [ ] 殴打：正面の相手に当たると、水平にまっすぐ吹っ飛ぶ
- [ ] 壁で 1 回跳ね返り、次の壁に薄くつぶれて貼り付く
- [ ] 貼り付いたあと少しずり落ち、2.6 秒で元に戻って点滅、3.6 秒で点滅が止まる
- [ ] 落下：餅を持っている相手を叩くと、餅がその場で跳ねて落ち、大きさはそのまま
- [ ] 味方に当たらない（今は 1 対 1 なので、2vs2 の時に再確認）
- [ ] 同時ヒット：向かい合って同時に振ると、両方吹っ飛ぶ
- [ ] 空振りすると少し動けない
- [ ] 吹っ飛んでいる人はほかの人をすり抜ける
- [ ] 壁未到達の延長：リンクの端から端へ飛ばされても、2 秒以内に貼り付くか、その場で復帰する
