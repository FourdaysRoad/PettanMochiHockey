# TASK-0030 公開版での確認：ロード画面（タイトルロゴと進捗バー）

エディタでの作業はない（テンプレート `Assets/WebGLTemplates/MochiHockey/` を作り替えただけで、Player Settings の WebGL Template は TASK-0003 のまま）。
push して CI が公開したあと、GitHub Pages の公開版で確かめる。

## できたこと

- ロード中、ゲームの色（タイトル画面と同じ紺・クリーム・黄・橙）で、次を表示する
  - タイトルロゴ「Pettan! / MOCHI HOCKEY」（画像を使わず、文字と CSS で描く）
  - 跳ねてつぶれる餅（CSS のアニメーション。「動きを減らす」設定のブラウザでは止まる）
  - 黄色から橙の進捗バーと「Loading... 42%」。読み込みが終わると「Starting...」になり、ゲームが始まったら 0.4 秒で消える
- 起動に失敗したら、ポップアップではなく進捗の文字の場所に理由を出す
- ページのタイトルと下のバーを「Pettan! MOCHI HOCKEY」にした（Unity のロゴは外した）
- 使わなくなった Unity のロゴ・標準の進捗バーの画像を外した

## 確かめること

1. 公開版を開き、**Ctrl + Shift + R** で読み込み直す
   - [ ] タイトルロゴ・跳ねる餅・進捗バーが出て、バーが右へ伸びる
   - [ ] 読み込みが終わると、ロード画面がふっと消えてタイトル画面になる
2. 回線を遅くして、進捗バーがゆっくり進むのを見る
   1. **F12** で開発者ツールを開き、**Network** タブを選ぶ
   2. **Disable cache** にチェックを入れ、上の「No throttling」を **Fast 4G**（遅すぎるなら Slow 4G）にする
   3. **Ctrl + Shift + R** で読み込み直す
   - [ ] バーが少しずつ伸び、パーセントが増えていく
   4. 終わったら「No throttling」に戻し、Disable cache のチェックを外す
3. 画面の大きさ
   - [ ] ウィンドウの大きさを変えても、ロード画面もゲームも 16:9 のまま
   - [ ] ゲームが始まったあと、F キー（または右下のボタン）でフルスクリーンになり、もう一度で戻る
