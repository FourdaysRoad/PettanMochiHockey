# TASK-0016 エディタ作業手順：杵の当たり判定とチーム

CLAUDE.md の決まりで、シーンの YAML は直接書かず、この手順で Unity エディタから作る。
前提：TASK-0014・TASK-0015 の手順で `Match` シーンにプレイヤー 2 人と餅があること。

杵の当たり判定はコードで体の正面に作るので、杵の子オブジェクトやレイヤーの設定はいらない。

## 1. プレイヤーに杵とチームを設定する

1. `Match` シーンを開く
2. `Player1` を選び、次を設定する
   - **Player Controller → Team**：`A`
   - **Add Component → Mallet Hitbox**
3. `Player2` を選び、次を設定する
   - **Player Controller → Team**：`B`
   - **Add Component → Mallet Hitbox**
4. （任意）Scene ビューで `Player1` を選ぶと、杵の当たり判定が黄色い球で表示される

## 2. 保存と動作確認

1. **File → Save**（シーン）
2. Play して次を確かめる
   - P1 は `K`、P2 はテンキー `2` で杵を振る
   - 相手が正面の近くにいると、一瞬止まってから攻撃者の正面方向へ水平にまっすぐ吹っ飛び、壁で 1 回跳ね返って、次に当たった壁に貼り付く（薄くつぶれる）
   - 1.5 秒ごろから壁沿いに少し下がり、2.6 秒で元の大きさに戻って点滅し、3.6 秒で点滅が止まる
   - 餅を持っている相手を叩くと、餅がその場で軽く跳ねて落ちる
   - 誰もいないところで振ると、少しの間動けない（空振りの硬直）
   - 吹っ飛んでいる間は、ほかのプレイヤーにぶつからずにすり抜ける
3. 終わったら Unity を閉じる（バッチモードのテストを動かすため）
