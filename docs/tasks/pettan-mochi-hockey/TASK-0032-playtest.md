# TASK-0032 試遊シート：バランス調整

数値はすべて `Assets/_Project/ScriptableObjects/GameBalanceConfig`（Inspector）にある。コードには調整用の数値はない（2026-11-19 に確認）。
「仮」と付いているのは、仕様書に値がなく、遊びながら決める項目。

## 調整のしかた

1. Unity で `GameBalanceConfig` を選び、Inspector で値を変える
2. **Play し直す**（ほとんどの値はプレイヤーなどが作られるときに読むので、Play 中に変えても反映されない）
3. 気になったことは、下の「感想メモ」に書くか、そのまま Claude に伝える（「ダッシュが弱い」くらいの言い方で大丈夫。数値は Claude が提案する）

> Play 中に Inspector で変えた値は、Play を止めても **元に戻らない**（ScriptableObject のため）。試した値を残したくなければ、メモしておいて戻す。
