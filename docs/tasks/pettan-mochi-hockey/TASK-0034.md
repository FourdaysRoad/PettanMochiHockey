## 決めたこと（2026-11-19、ユーザー回答）

| 項目 | 決定 |
|---|---|
| ボタン | 壁の近くでダッシュを **長押し** → 矢印で狙う → 離すと飛ぶ。短く押したら今までどおりのダッシュ |
| 狙っている間 | 壁に張り付いて止まる（杵で叩かれるリスクがある） |
| 飛んでいる間 | 向きは変えられない。**杵は振れる**。餅を持ったままでは壁キックできない。体当たりで相手を飛ばすことはない |
| 連鎖 | 壁に着くと張り付き、**一定時間内にダッシュを押せば** 次を狙える。蹴るほど速くなる（上限あり）。時間切れ・叩かれたら終わる |

## 状態の流れ（Core の WallKick）

```
None ──ダッシュを押す（壁の近く・餅なし）──▶ Holding ──長押し──▶ Aiming ──離す──▶ Flying ──壁に着く──▶ Clinging
  ▲            │短く離す → 通常のダッシュ                     │狙いすぎ → 自動で飛ぶ                       │受付時間内にダッシュ → Aiming（連鎖 +1）
  └────────────┴──────────────── 叩かれる・受付時間切れ・飛びすぎ（連鎖 0 に戻る） ◀─────────────────────────┘
```

## 補足（実装で決めたこと）

- 壁キック中（狙っている・飛んでいる・張り付いている間）は餅を拾えない
- 長押しを待っている間に餅を拾ったら、壁キックはやめてふつうのダッシュにする
- 狙い始めたとき・飛んだ先の壁に着いたときは、体を壁にぴったり付ける
- 飛んでいる途中で終わった（飛びすぎ）ときは、その勢いのまま滑る
- エディタでの作業はない（矢印と連鎖の表示は WorldGaugePresenter が作る）
- 2026-11-19 の試遊で「もったりする」→ 長押し 0.18→0.12 秒、1 回目 14→18 m/s、上がり幅 0.25→0.2、上限 26→32 m/s にして「良くなった」
