## タスク概要

ボタンを押したデバイスから順に参加させ、番号（1P〜4P）とチームを決め、Menu → Match シーンへ引き継ぐ仕組みを作る。

## 完了条件

- [ ] ボタンを押したデバイスが順に 1P〜4P として参加する
- [ ] キーボード 1 台で 2 人（P1 / P2 スキーム）参加できる
- [ ] チームを割り当てられる（1vs1 / 2vs2）
- [ ] Match シーンで同じデバイス・番号・チームでプレイヤーが生成される
- [ ] PlayMode テストが通る
