# アセットの選定とライセンス（TASK-0027）

**作成日**: 2026-11-18

## 前提（守ること）

- リポジトリは公開のまま、GitHub Actions（CI）でリポジトリの中身から WebGL をビルドして GitHub Pages に公開する。
- そのため、**アセットのファイルそのものを公開リポジトリに入れてよいライセンス**だけを使う。
  - ゲームに組み込んで公開・販売してよい、だけでは足りない（リポジトリにはモデル・テクスチャ・音のファイルがそのまま入る）。
- Compute Shader に依存するアセットは使わない（WebGL で動かない）。
- ローポリ・トゥーン調を優先し、テクスチャは 1024px 以下。

## 決めたこと（2026-11-18、ユーザー回答）

| 項目 | 決定 |
|---|---|
| 素材の出どころ | **CC0（パブリックドメイン）の無料アセット**を使う。CC0 で見つからないものはプリミティブ（球・円柱・立方体）を組み合わせて自作する |
| Asset Store | 使わない（標準 EULA ではアセットの再配布が禁止のため、公開リポジトリに入れられない） |
| ピヨり（めまい） | **復帰直後の無敵中**（1 秒間）に、頭の上で星を回す |

## 調べた候補

| 出どころ | ライセンス（確認日） | 公開リポジトリに入れてよいか | 使えそうなもの |
|---|---|---|---|
| [Kenney「Cube Pets」](https://kenney.nl/assets/cube-pets) | **Creative Commons CC0**（2026-11-18 に配布ページで確認） | よい（CC0） | アニメーション付きの四角い動物 24 体。プレビュー画像に白いウサギらしきキャラクターが見えるが、中身はダウンロードして確認が必要 |
| [Quaternius](https://quaternius.com/) | **Quaternius Asset License (QAL) v1.0**（2026-08-28 更新）。以前の CC0 から変わっている | **はっきりしない**。ゲームに組み込んで配るのは自由だが、「アセットそのものを再配布してはいけない」とあり、公開リポジトリに生のファイルを置くことがこれに当たるかは書かれていない | 動物・キャラクター・小物が多い。使う場合は作者に問い合わせてから |
| 検索で見つかったウサギのモデル（CGTrader など） | 有料、または CC0 ではない独自ライセンス | 不可、または不明 | 使わない |

参考：Kenney は「クレジットは必須ではない」としている。

## 方針

1. **ウサギ（プレイヤー）**：Kenney「Cube Pets」を使う。ウサギが入っていなければ、近い動物で代用するか、プリミティブで自作する。
2. **杵・臼・餅・リンク**：CC0 で合うものが見つからなかったので、プリミティブを組み合わせて作る（臼＝太い円柱＋くぼみ、杵＝細い円柱の柄＋太い円柱の頭、餅＝白い球、リンク＝白い床と青い壁）。
3. **アニメーション**：Cube Pets に入っているアニメーションを使う。足りない動き（杵のスイング・被弾）は、コードで体を傾けたり伸び縮みさせたりして表現する。
4. **ピヨり**：コードで星を作って頭の上で回す（アセット不要）。

## 使うアセットを入れるとき

- `Assets/_Project/Art/ThirdParty/<パック名>/` に置き、同じフォルダに配布元の `License.txt` を一緒に入れる。
- この表に、パック名・配布元 URL・ライセンス・確認日を追記する。
